# Evaluation Scripts

This directory contains scripts for evaluating the performance of the model.

## Overview

The evaluation scripts are designed to evaluate the performance of the model on the base question evaluation data.

## Scripts

1. `prepare_data.py` - Prepare the data for evaluation.
Install the mh-oan/sunbird-va-api project and change the path to the project root in the script.


2. `evaluate_model.py` - Evaluate the model on the data.
